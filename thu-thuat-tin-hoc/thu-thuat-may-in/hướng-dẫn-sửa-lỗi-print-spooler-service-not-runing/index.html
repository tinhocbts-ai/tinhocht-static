Hướng Dẫn Sửa Lỗi Print spooler service not runing

Giải thích vấn đề: Print spooler là một dịch vụ hỗ trợ cho quá trình in ấn, vì lý do gì đó như máy tính bị virus, lỗi chương trình hệ thống... mà gây ra lỗi Print Spooler.

Triệu chứng lỗi: Lỗi thường xuất hiện sau khởi động lại với thông báo "Spoolsv.exe Applicatin Error" và "Spooleer subsystem", không nhìn thấy máy in nào, không thể cài hoặc sử dụng Driver máy in.

Ba cách khắc phục:

Cách 1: Chạy phần mềm vá lỗi Microsoft (MicrosoftFixit50126.msi)

Cách 2: Vào Start -> Run -> gõ services.msc, sau đó bật automatic và khởi động lại các dịch vụ: "Print spooler", "computer Browser", "Background Intelligent Transfer Service"

Cách 3: Copy file spoolsv.exe từ các nguồn khác (máy tính khác, tải từ mạng, file ISO Windows) và copy đè lên file cũ tại đường dẫn "C:\Windows\system32\spoolsv.exe", sau đó khởi động lại máy

Giải pháp cuối cùng: Nếu các cách trên không hiệu quả, tiến hành diệt virus, sửa chữa Windows hoặc cài lại hệ điều hành.
